# جنى — حصن المسلم ورفيق الطالب

موقع + تطبيق جوال (PWA قابل للتثبيت على أندرويد) بحسابات موحّدة: ما تسجّله في الموقع تدخل به من الجوال، وتقدّمك (الأذكار، المهام، المسبحة) يتزامن.

## التشغيل محليًا
    npm install
    ADMIN_EMAIL=you@mail.com ADMIN_PASSWORD='كلمة-سر-قوية' npm start     # http://localhost:3000

إن لم تحدد ADMIN_PASSWORD تُولَّد كلمة سر عشوائية وتُطبع في الطرفية وتُحفظ في data/ADMIN-LOGIN.txt.

## الرفع على الإنترنت (مطلوب لتثبيته على الجوال)
يلزم عنوان HTTPS ومساحة تخزين دائمة لمجلد data (قاعدة البيانات والملفات الصوتية).
- أي استضافة Node (Render, Railway, Fly.io, VPS) أو Docker:
  docker build -t jana . && docker run -p 3000:3000 -v jana-data:/data -e ADMIN_EMAIL=... -e ADMIN_PASSWORD=... jana
- متغيرات البيئة: ADMIN_EMAIL, ADMIN_PASSWORD, JWT_SECRET (اختياري), DATA_DIR, PORT.

## التثبيت على أندرويد
1. افتح رابط الموقع في Chrome ← قائمة ⋮ ← «تثبيت التطبيق» (أو زر «تثبيت» داخل التطبيق).
2. لملف APK أو متجر Play: ادخل الرابط في https://www.pwabuilder.com واختر Android.

## لوحة التحكم (للمدير)
الإعدادات ← «لوحة التحكم»: المظهر (ألوان الفاتح والداكن، الخطوط، الشعار، قوالب)، عام (الاسم، الترحيب، إعلان، إظهار/إخفاء الأقسام، روابط التواصل، فتح/إغلاق التسجيل)، المحتوى (أقسام وأذكار وملفات صوتية)، المستخدمون (ترقية، إيقاف، إعادة كلمة سر، حذف).

## ملاحظات
- القراءة الصوتية تستخدم صوت الجهاز العربي؛ ارفع ملف mp3 لأي ذكر من لوحة التحكم ليُستخدم بدلًا منه.
- «نسيت كلمة السر» تعرض طريقة التواصل مع الإدارة (لا يوجد خادم بريد)؛ يعيد المدير تعيينها من لوحة المستخدمين.
- راجع نصوص الأذكار ومصادرها قبل النشر العام.
